# 安卓离线英语学习助手

这是一个可安装的离线 PWA。课程方法与图片 OCR 内置在 App 中，默认从国内可达镜像下载 Qwen3 本地模型，模型缓存成功后可以断网问答。

## 两个版本

- `/public/`：公开版，无需密码，只包含提炼后的阅读、写作方法，不包含课程逐字转写。
- `/private/`：私人版安装入口，目前已经取消密码；同样只包含提炼后的方法摘要，不公开逐字转写。
- 根地址 `/` 提供两个版本的安装入口。两个版本共享同一套 Qwen 模型缓存。

## 安卓安装

1. 使用最新版安卓 Chrome 打开部署后的 HTTPS 地址。
2. 等待离线资源缓存完成。
3. 点击“安装到手机桌面”；如果没有按钮，使用 Chrome 菜单中的“安装应用”或“添加到主屏幕”。
4. 默认选择 Qwen3 0.6B 验证 WebGPU，再尝试 1.7B。
5. 等模型显示“已加载，可断网使用”后再提问。

如果出现 `GPUBuffer`、`external Instance` 或 `mapAsync` 错误，请退出重开 App，使用 0.6B，关闭其他大型应用并保持页面在前台。

## 自动更新

项目包含 `.github/workflows/deploy-offline-pages.yml`。推送到 GitHub `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。

首次发布前：

1. 在仓库 Settings → Pages 中把 Source 设置为 GitHub Actions。
2. 等待 Actions 发布完成。
3. 手机使用固定 Pages 地址安装 App。

以后修改课程资料或 App 后推送代码，手机联网打开 App 会检测到新版本并显示“立即更新”。模型缓存不需要重新下载。

## 隐私提醒

GitHub Pages 是公开站点。两个版本目前都只发布高层方法摘要，不包含老师的课程逐字转写。发布摘要前仍需确认你对课程内容拥有相应使用和加工权限。
